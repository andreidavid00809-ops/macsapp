# macsapp

A student subject tracker app with user authentication, notes, deadline reminders, smart notifications, and progress tracking.

## Features
- User sign up and login
- Track subjects and assignments
- Add notes/tasks with deadlines
- Smart notifications for tasks due within 24 hours
- Progress bar for completed work
- Simple calendar view for upcoming deadlines

## Run locally

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Open the app in your browser:
   http://localhost:3000

## Notes
- The app uses a local JSON database in `data/db.json`.
- Notification reminders are checked automatically every 30 seconds.
